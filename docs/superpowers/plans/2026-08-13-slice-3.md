# Slice 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver layers, pooled materials, delta-based undo/redo, immutable version history, IndexedDB recovery, and safe 409 conflict resolution for the five editable right-hand nails.

**Architecture:** Pure document commands live outside Zustand and are stored in a bounded history ring. The store coordinates command results with editor revision and UI state. Version and offline-draft features remain separate persistence adapters, joined in the editor through explicit recovery/conflict dialogs.

**Tech Stack:** TypeScript 7, React 19, Zustand 5, Three.js 0.185, TanStack Query 5, Express 5, Prisma 7, PostgreSQL, Zod 4, Vitest 4, native IndexedDB.

## Global Constraints

- “Apply to all nails” affects only `EDITABLE_NAILS`, the five editable right-hand nails.
- Left-hand nail data must remain unchanged by bulk editor commands.
- `DesignVersion.document` is immutable; only `label` may change.
- History stores deltas, never cloned `DesignDocument` snapshots, and is capped at 100 entries.
- Mergeable commands coalesce only when their `mergeKey` matches within 500 ms.
- Recovery and conflict flows require an explicit user choice and never force overwrite.
- New production behavior must follow red-green-refactor.
