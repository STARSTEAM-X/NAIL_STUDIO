# Realistic Interactive Hand Model — Technical Specification

**รหัสเอกสาร:** RIH-3D-SPEC  
**เวอร์ชัน:** 1.0  
**วันที่:** 18 ตุลาคม 2026  
**สถานะ:** ข้อกำหนดสำหรับออกแบบ พัฒนา และทดสอบ  
**ขอบเขต:** โมเดลมือ 3D และระบบปฏิสัมพันธ์ ไม่ผูกกับ Framework หรือโค้ดของเว็บไซต์

---

## 1. ภาพรวมโครงการ (Project Overview)

### 1.1 เป้าหมาย
พัฒนา **โมเดลมือมนุษย์ 3D แบบสมจริง (Realistic Interactive Hand Model)** ที่สามารถปรับแต่งสีผิว สัดส่วน นิ้วมือ ท่าทาง รูปทรงเล็บ ความยาว วัสดุ ลวดลาย และเครื่องประดับได้แบบ Real-time โดยใช้ **โมเดลพื้นฐานที่นำกลับมาใช้ซ้ำได้** ไม่ต้องปั้นหรือโหลดโมเดลมือใหม่ทุกครั้งที่เปลี่ยนแบบเล็บ

รองรับการใช้งานเพื่อพรีวิวดีไซน์เล็บ เปรียบเทียบผลงาน และถ่ายภาพจำลองสำหรับร้านทำเล็บ

### 1.2 หลักการออกแบบ
1. **One Reusable Hand Asset:** โมเดลมือหลักสามารถใช้ซ้ำได้กับทุกดีไซน์
2. **Independent Nail Assets:** เล็บ 10 นิ้วเป็น Mesh/Geometry แยกจากผิวมือ พร้อมกำหนดรูปทรง วัสดุ และลายรายนิ้ว
3. **Rigged & Poseable:** มือมี Skeleton, Skinning และข้อต่อนิ้วที่ขยับจริง
4. **Non-Destructive Customization:** การแก้ดีไซน์ไม่เปลี่ยนหรือทำลายต้นฉบับโมเดล
5. **Persistent Attachment:** เล็บและของตกแต่งยึดกับปลายนิ้วแม้เปลี่ยนท่า/สัดส่วน
6. **State-Driven:** บันทึกทุกค่าที่เปลี่ยนเป็นข้อมูลและเรียกคืนสภาพเดิมได้

### 1.3 สิ่งที่ไม่อยู่ในขอบเขตของเวอร์ชันแรก
- การสแกนมือผู้ใช้แบบ 3D จากภาพถ่ายเพื่อให้ตรงกับมือจริงทุกมิติ
- ระบบ AR ติดตามมือจากกล้องแบบเรียลไทม์
- ระบบฟิสิกส์ผิวนุ่มและผิวหนังระดับภาพยนตร์
- การจำลองขั้นตอนทำเล็บจริง เช่น ตะไบ ตัด หรือทากาวแบบฟิสิกส์
- ระบบร้านค้า การจองคิว การชำระเงิน หรือส่วนอื่นของเว็บไซต์

### 3.1 โครงสร้างโมเดลที่ต้องส่งมอบ

```text
HandSystem
├── LeftHand
│   ├── HandMesh (skinned)
│   ├── Skeleton / FingerBones
│   └── NailSockets
│       ├── Thumb_NailRoot → NailMesh → Decorations[]
│       ├── Index_NailRoot → NailMesh → Decorations[]
│       ├── Middle_NailRoot → NailMesh → Decorations[]
│       ├── Ring_NailRoot → NailMesh → Decorations[]
│       └── Pinky_NailRoot → NailMesh → Decorations[]
├── RightHand (โครงสร้างเทียบเท่ากัน)
├── PoseController
├── NailCustomizer
├── MaterialLibrary
├── LightingRig
└── CameraController
```

**หมายเหตุ:** `NailRoot` เป็นจุดยึด (Socket/Anchor) ที่อ้างอิงกระดูกปลายนิ้วและตำแหน่งโคนเล็บ ไม่ใช่การวางเล็บด้วยพิกัดโลกแบบตายตัว

### 3.2 ระบบกระดูกและข้อจำกัดการเคลื่อนไหว
- มีข้อมือและกระดูกสำหรับนิ้วทั้งห้า โดยควบคุมข้อต่อที่สัมพันธ์กับ MCP, PIP, DIP ของ 4 นิ้ว และ CMC, MCP, IP ของนิ้วหัวแม่มือ
- รองรับ **Flexion/Extension** (งอ/เหยียด), **Abduction/Adduction** (กาง/หุบ) ที่ข้อต่อเหมาะสม และ **Thumb Opposition** (การหุบ/ประกบนิ้วหัวแม่มือ)
- ใช้ขอบเขตการหมุนข้อต่อ (Joint Limits) เพื่อป้องกันการบิดผิดกายวิภาค
- มีการเปลี่ยนท่าแบบ Smooth Interpolation; หลีกเลี่ยงนิ้วหัก มือละลาย หรือ Mesh ยุบผิดรูป
- รองรับการควบคุมมือซ้ายและมือขวาแยกกัน

### 4.1 พารามิเตอร์ของเล็บต่อหนึ่งนิ้ว
- `shape`: ทรงเล็บ
- `length`: ความยาวจริงในหน่วยโมเดลที่กำหนด หรือ Normalized Value 0–1
- `width`, `curvature`, `taper`, `tipWidth`: ขนาด/สัดส่วน
- `baseColor`, `tipColor`, `opacity`: สีและความโปร่งใส
- `finish`, `roughness`, `metalness`: ประเภทวัสดุ/ผิวเคลือบ
- `pattern`: ประเภทลายและพารามิเตอร์ (เช่น องศา ความหนา French Tip, จุดเริ่ม Fade)
- `decals[]`: สติกเกอร์หรือกราฟิก 2D
- `decorations[]`: ของตกแต่ง 3D พร้อมตำแหน่ง หมุน และสเกล

### 4.2 ระบบสร้างและเปลี่ยนทรงเล็บ
- ใช้ **Parametric Nail Geometry / Morph Targets / Nail Shape Presets** เพื่อปรับ Mesh ของเล็บ ไม่ใช่โมเดลมือ
- ตำแหน่งโคนเล็บต้องอยู่ตาม nail bed และระนาบนิ้วอย่างสมจริง
- ความยาวเพิ่มไปทางปลายนิ้วโดยไม่ทำให้โคนเล็บขยับหลุด
- รูปร่างเล็บต้องคงความหนาที่ดูสมจริงและไม่มีขอบคม/พื้นผิวกลับด้าน
- เมื่อเปลี่ยนทรงหรือความยาว ระบบต้องตรวจสอบการชนหรือทะลุกับผิวและของตกแต่ง

### 4.3 การเรนเดอร์ลวดลายและวัสดุ
- **Nail Layers:** Base → Color → Pattern/Gradient → Finish → Decal → 3D Decoration
- Ombre ต้องควบคุมทิศทาง ตำแหน่งรอยต่อ และความนุ่มของการไล่สี
- French Tip ต้องควบคุมสัดส่วนปลายเล็บและรูปทรงเส้นขอบได้
- Chrome ต้องตอบสนองต่อแสงและสิ่งแวดล้อม ไม่ใช่แค่ใช้สีเทาเรียบ
- Jelly ต้องให้ลักษณะโปร่งแสง/มีมิติ โดยเลือกวิธีเรนเดอร์ที่เหมาะกับประสิทธิภาพ
- Glitter และ Cat Eye ต้องเปลี่ยนประกายตามมุมกล้องหรือแสงอย่างสอดคล้อง
- Texture/Decal ต้องถูกแมปตาม UV หรือพิกัดบนผิวเล็บ เพื่อไม่ให้ลายหลุดเมื่อเล็บเปลี่ยนขนาด

## 8. การปรับแต่งรูปลักษณ์และส่วนเสริม

### 8.1 Skin Customization (P1)
- สีผิวแบบปรับต่อเนื่อง หรือ preset หลายโทน
- ความหยาบ/ความเงา ความเด่นของรอยพับ และรายละเอียดผิว
- สีผิวต้องแสดงผลอย่างสอดคล้องภายใต้แสงเดียวกัน เพื่อใช้ประเมินคู่สีเล็บ
- อาจรองรับ Subsurface Scattering แบบปรับระดับคุณภาพเพื่อเพิ่มความสมจริง

### 8.2 Hand Proportions (P2)
- ความยาวนิ้วรายนิ้ว
- ความกว้าง/ความหนาฝ่ามือ และความหนาของนิ้ว
- ใช้ Rig Retargeting / Morph Targets ตามชนิดการแก้ไข
- ไม่อนุญาตให้การปรับค่าทำให้เล็บลอยผิดตำแหน่งหรือเกิด geometry พัง

### 8.3 Accessories (P2)
- แหวนและกำไล แยกเป็น Asset
- มีจุดยึดที่นิ้ว/ข้อมือ และปรับขนาดตามสัดส่วนมือ
- ปรับวัสดุ สี และตำแหน่งได้

## 10. ข้อกำหนดด้านคุณภาพและประสิทธิภาพ (Non-Functional Requirements)

| ID | เกณฑ์เป้าหมาย | Priority |
|---|---|---|
| NFR-001 | ภาพมือ เล็บ โคนเล็บ และแสงเงาดูสมจริงในระยะใช้งานปกติ | P0 |
| NFR-002 | เปลี่ยนสี/วัสดุ/ลายแล้วแสดงผลได้ทันทีโดยไม่โหลด Hand Asset ใหม่ | P0 |
| NFR-003 | เปลี่ยนทรงหรือความยาวโดยอัปเดตเฉพาะเล็บที่เกี่ยวข้อง | P0 |

| NFR-005 | มีการลดคุณภาพตามอุปกรณ์ (LOD, Texture Resolution, Shadow Quality) | P1 |

### 10.1 ความปลอดภัยของ Geometry
- ไม่มีผิวกลับด้าน (inverted normals) หรือรูโหว่ของเล็บ
- ผิวมือไม่แตก/พับทับกันผิดธรรมชาติในช่วงมุมข้อต่อที่อนุญาต
- เล็บไม่ลอยและไม่ทะลุผิวหนังอย่างเห็นได้ชัดในท่าและสัดส่วนที่รองรับ
- เล็บทั้งสิบต้องระบุ ID แน่นอน โดยไม่สลับนิ้วหรือสลับซ้าย–ขวา

## 13. Deliverables สำหรับทีม 3D / ทีม Runtime

1. **Hand Asset:** โมเดลมือซ้าย–ขวาที่มี UV, Skin Weights, Skeleton และวัสดุพร้อมใช้
2. **Nail Asset System:** เล็บ 10 ตำแหน่ง พร้อม Shape Presets, Parametric/Morph Controls และจุดยึด
3. **Material Library:** Skin, Nail Finish, Pattern, Gradient, Decal และตัวอย่าง Decoration
4. **Pose Library:** Pose Presets ตามข้อ 5 และระบบปรับ Joint แยกรายข้อ
5. **Scene Setup:** แสง Studio/Daylight/Warm/Cool และ Camera Presets
6. **State Specification:** ค่าพารามิเตอร์ Schema ตัวอย่างข้อมูล และวิธี Load/Save
7. **Export Package:** GLB/glTF 2.0 หรือฟอร์แมตที่ตกลงร่วมกัน, Texture, Material Assets, Pose Data และเอกสารการเชื่อมต่อ
8. **Acceptance Test Report:** หลักฐานทดสอบ AT-01 ถึง AT-14 เท่าที่รวมในเฟสส่งมอบ พร้อม Performance Benchmark
9. **Source Files:** ไฟล์ต้นฉบับของงาน 3D (เช่น Blender) และเงื่อนไขสิทธิ์การใช้งาน Asset ที่ชัดเจน

## 14. ลำดับพัฒนา (Implementation Phases)

### Phase 1 — Functional MVP (P0)
- โมเดลมือสมจริง 1 มือพร้อม Rig
- เล็บแยก 5 นิ้ว และทรง/ความยาวเปลี่ยนได้
- สี, French Tip, Ombre และพื้นผิวพื้นฐาน
- Pose Presets + Finger Controls + 360° Camera
- Smart Nail Attachment ขั้นพื้นฐาน
- บันทึก/โหลด State และผ่าน AT-01 ถึง AT-05, AT-07, AT-09

### Phase 2 — Production Nail Studio (P1)
- สองมือ 10 นิ้วและการเปรียบเทียบ
- วัสดุขั้นสูง Chrome, Jelly, Glitter, Cat Eye
- Decorations 3D และ Smart Attachment ขั้นสูง
- Skin Customization, Lighting Presets, Photo Mode
- Custom Poses, Undo/Redo, Performance Optimization
- ทดสอบเกณฑ์ AT ที่เหลือสำหรับ P1

### Phase 3 — Advanced Customization (P2)
- ปรับสัดส่วนมือและนิ้ว
- แหวน กำไล และส่วนเสริม
- แอนิเมชันโชว์เล็บและ Timeline/Pause
- ระบบคุณภาพภาพขั้นสูงตามความสามารถอุปกรณ์

## 15. Definition of Done

ถือว่าส่งมอบ **ระบบหลัก (P0)** ได้เมื่อ:

- ใช้โมเดลมือเดิมในการสลับดีไซน์โดยไม่ต้องสร้าง Hand Mesh ใหม่
- เล็บทุกนิ้วเปลี่ยนทรง ความยาว สี และลายได้อย่างเป็นอิสระ
- นิ้วและข้อต่อขยับจริงตาม Rig; ไม่ใช่การหมุนมือทั้งชิ้นเพื่อปลอมเป็น Pose
- เล็บเคลื่อนตามนิ้วทุก Pose ที่รองรับโดยไม่มีการหลุดหรือตัดผ่านผิวอย่างเห็นได้ชัด
- ควบคุมกล้อง 360° ได้และบันทึก/เรียกคืน State ได้
- ผ่าน Acceptance Tests ที่กำหนดให้เป็น P0 และไม่มี Defect ร้ายแรงที่ทำให้ใช้งานไม่ได้

**เป้าหมายสุดท้าย:** *หนึ่งระบบโมเดลมือที่สามารถสร้างพรีวิวเล็บได้ไม่จำกัดจำนวนดีไซน์ผ่านการปรับพารามิเตอร์และ Asset ที่ใช้ซ้ำ — ไม่ใช่การปั้นมือใหม่หนึ่งชุดต่อหนึ่งดีไซน์*
