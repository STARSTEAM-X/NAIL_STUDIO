## การตรวจสอบไฟล์

ทั้ง 10 ไฟล์ผ่านการตรวจด้วย `@dbml/core` เวอร์ชัน 10.1.1 ซึ่งเป็น parser ตัวเดียวกับที่
dbdiagram.io ใช้ ทั้งขั้น `Parser.parse()` และขั้นส่งออกเป็น PostgreSQL (`ModelExporter`)
และทดสอบวางในหน้าเว็บ dbdiagram.io จริงแล้วขึ้น 0 error

ข้อควรระวังของไวยากรณ์ DBML ที่เจอตอนตรวจ:

- **enum ต้องเขียนค่าละบรรทัด** — `Enum s { a b c }` แบบบรรทัดเดียวจะ parse ไม่ผ่าน
- ชนิดข้อมูลที่มีวงเล็บเหลี่ยมหรือไม่ใช่ชนิดมาตรฐาน ต้องครอบด้วยเครื่องหมายคำพูด
  เช่น `"text[]"` และ `"vector(768)"`
- `[type: hnsw]` ในบล็อก `indexes` ไม่รองรับ จึงเขียนไว้เป็น note แทน

## วิธีส่งออกเป็นรูป

1. วางไฟล์ใน <https://dbdiagram.io/d>
2. ปุ่ม **Export** มุมขวาบน → เลือก PNG หรือ PDF
3. ถ้าต้องการ SQL: **Export → PostgreSQL** (ได้ `CREATE TABLE` ครบ)

> หมายเหตุ: DBML ไม่รองรับ `DESC` ในดัชนี, partial index, `CHECK` และ `EXCLUDE`
> สิ่งเหล่านี้เขียนไว้เป็น note ในไฟล์ และสรุปรวมไว้ในหัวข้อ 8 ของ `ANALYSIS.md`
